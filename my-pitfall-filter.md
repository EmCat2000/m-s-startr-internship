# My pitfall filter

A pitfall filter is a short list of common planning traps, in plain words. A plan goes in, and any trap it matches comes back flagged, so a person can take a look.

Here are three traps to start. Read them, then add your own at the bottom.

## Starter traps

- **No buffer.** Every hour booked back to back, so the first thing that runs long knocks over everything after it.
- **No first step.** A goal with no clear "do this first", so it never quite gets going.
- **The multitasking myth.** Doing two things at once to save time, which usually makes both take longer.

## Your trap

Add one trap you've actually run into. Give it a short name and one plain sentence.

- **(your trap name).** What it looks like, in your own words.

---

When you're happy with your trap, that's a save point worth keeping. Head back to the guide and make your first commit.
